# Exploratory pilot (historical)

The pilot was an exploratory six-condition study. It identified several candidate effects, but because multiple representational variables were compared simultaneously, the follow-up suite decomposes those comparisons into smaller controlled experiments.

This directory is a byte-for-byte snapshot of every pilot file that was tracked when the follow-up suite was created: its benchmark code, artifacts, fixtures, preregistration metadata, tests, README, and project configuration. The repository did not contain checked-in raw result or generated report files, so none could be copied here. The snapshot is not part of the numbered experiment chain.

Do not regenerate or edit the snapshot's artifacts, hashes, or preregistration metadata.
