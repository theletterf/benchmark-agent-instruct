# Phase 2 — Real documentation

This phase reproduces the nine Phase 1 independent variables against frozen primary-source technical documentation. It does not alter the fable artifacts or results.

The benchmark engine lives in `benchmark/real_docs/`. Project-specific sources, task manifests, fixtures, classifiers, and frozen artifacts live under `projects/`.

SQLAlchemy is preserved as a completed negative candidate-selection result: Sonnet 4.6 was 80% current without documentation and 100% current with ordinary official documentation, so the remaining battery had no usable primary-metric headroom.

OpenTelemetry is the active candidate. It currently contains only frozen sources, candidate conflicts, decision manifests, tasks, deterministic scoring, and two calibration stages. Its nine experiment artifacts must not be created until official-documentation calibration leaves meaningful decision-level headroom.

Paid execution is gated by a task-only prior calibration and explicit run commands.
