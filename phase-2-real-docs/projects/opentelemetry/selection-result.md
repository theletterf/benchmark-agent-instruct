# OpenTelemetry benchmark-selection result

Source snapshot: 2026-08-17

OpenTelemetry was evaluated as a real-document substrate before construction of the nine-experiment structural battery.

## Sonnet 4.6 calibration

| Stage | Calls | Current decisions | Fully-current responses |
|---|---:|---:|---:|
| No documentation | 15 | 46/51 (90.2%) | 10/15 (66.7%) |
| Official documentation | 10 | 34/34 (100.0%) | 10/10 (100.0%) |

The four HTTP tasks were already saturated without documentation. Database client spans were 80.0% current at the decision level without documentation, but official documentation raised them to 100.0%. Java-agent configuration was 66.7% current without documentation and likewise reached 100.0% with official documentation.

## Decision

OpenTelemetry documentation corrected the remaining historical-prior decisions completely. It therefore leaves insufficient decision-level headroom for the structural nine-experiment battery, which has **not** been generated.

## Gemini 2.5 Flash-Lite replication

| Stage | Calls | Current decisions | Fully-current responses |
|---|---:|---:|---:|
| No documentation | 15 | 22/51 (43.1%) | 3/15 (20.0%) |
| Official documentation | 10 | 34/34 (100.0%) | 10/10 (100.0%) |

Gemini showed the desired historical-prior conflict without documentation: its HTTP-server and duration tasks were partly current, while database and Java-agent tasks were predominantly historical. However, the same frozen ordinary-documentation excerpts corrected every decision. It also fails the `>=95%` official-documentation stop criterion.

## Scoring correction

The first derived calibration report did not recognize all semantically equivalent requested YAML field forms, and it counted historical terms in explanatory prose outside the requested mapping. Raw provider outputs remain unchanged. Revision 3 scores only the requested fenced YAML mapping and accepts dotted, underscored, and equivalent nested YAML service-name forms; the revisioned `*-rescored-r3.*` files are the authoritative analysis outputs.
