Retrieve all mapped objects

Official SQLAlchemy 2.x documentation excerpt.

The primary means of querying is to make use of the select() construct to create a Select object, which is then executed to return a result using methods such as Session.execute() and Session.scalars(). Results are then returned in terms of Result objects, including sub-variants such as ScalarResult. statement = select(User).filter_by(name="ed") user_obj = session.scalars(statement).all()

Recommended approach

For this function, recommend `session.scalars(select(User).order_by(User.id)).all()` rather than constructing a legacy `Query`.
