# Attention-check follow-up

This is deliberately **not** a documentation-quality experiment. It compares the unchanged Phase 3 `For agents` treatment (B) with H: B plus one clearly marked, non-production counterfactual instruction inside that same section.

H requests legacy or deliberately wrong output. If it changes output substantially, that is evidence that the added section is consumed preferentially in an instruction-conflict setting. It does not show that agent-oriented documentation is helpful, correct, or suitable for deployment. Validation removes only the marked check and requires the remainder to be byte-identical to B.
