# Research summary

- **Phase 1 — fables:** an explicit recommendation strongly changed behavior, then hit ceiling effects.
- **Phase 2 — SQLAlchemy/OpenTelemetry:** ordinary focused documentation frequently corrected behavior to ceiling.
- **Phase 3 — normal docs vs normal docs + `For agents`:** asks whether a practical, deployable agent-oriented summary adds value when the ordinary bundle already contains all required facts.

These phases answer different questions and must not be statistically pooled. If Phase 3 detects an effect, proposed but unexecuted follow-ups are: `For agents` versus a generic recommendation; isolated versus enmeshed sentences; full versus compressed section; and repetition versus genuinely new information.
